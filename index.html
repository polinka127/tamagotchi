Річний проєкт · 10 клас · Python

Віртуальний вихованець (Тамагочі)

Цей проєкт присвячений створенню екосистеми програмних рішень для взаємодії з цифровим улюбленцем на мові Python. Концепція дозволяє поєднати ігрову механіку, автоматизацію сповіщень, веб-візуалізацію та настільні інтерфейси в межах однієї спільної ідеї. Робота над темою допомагає закріпити базові навички програмування та опанувати різні інструменти розробки без використання персональних даних реальних людей.

01

Гра

Симулятор догляду за піксельним улюбленцем, де гравцеві потрібно стежити за його рівнем ситості, здоров'ям та настроєм.

2D-симуляція · Pygame
02

Бот

Телеграм-помічник, який надсилає нагадування погодувати віртуальну тварину та дозволяє взаємодіяти з нею через кнопки.

Сповіщення · Telegram API
03

Сайт

Інтерактивна вітрина з галереєю видів вихованців, описом їхніх характеристик та базовими порадами щодо догляду.

Веб-вітрина · HTML / CSS
04

Застосунок

Десктопний трекер стану улюбленця з компактним віджетом для відображення основних показників на робочому столі.

Десктоп GUI · Tkinter / PyQt
