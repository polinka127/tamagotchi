# tamagotchi
Тема: Віртуальний вихованець.
Гра: Симулятор догляду за піксельним улюбленцем, де треба стежити за його ситістю, здоров'ям та настроєм.
Бот: Телеграм-помічник, який надсилає нагадування погодувати віртуального тварина та дозволяє грати з ним через кнопки.
Сайт: Інтерактивна вітрина з галереєю видів вихованців, їхніми характеристиками та порадами щодо догляду.
Застосунок: Десктопний трекер стану улюбленця із віджетом на робочому столі.
